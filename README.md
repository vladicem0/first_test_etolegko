# Измерение скорости скачивания по HTTP

Скрипт десять раз подряд скачивает ресурс по указанному URL. Следующий запрос начинается после чтения всего тела предыдущего ответа. Файл читается частями по 64 КиБ и не сохраняется на диск.

## Запуск

Требуется Python 3.8 или новее. Все зависимости входят в стандартную библиотеку. Для пробного запуска можно использовать готовый файл на Google Диске. Выполните команду из каталога проекта.

```sh
python benchmark.py "https://drive.usercontent.google.com/download?id=1d_0a-zCi_4_AMITxgheCPhbxLU4Z406c&export=download&confirm=t"
```

Размер тестового файла — 30 147 893 байта. После десяти скачиваний ожидаемый результат — `Скачано всего: 301478930 байт`.

Чтобы проверить другой ресурс, замените адрес в кавычках своим HTTP- или HTTPS-адресом. Для замера скорости лучше выбрать прямую ссылку на файл размером в несколько мегабайт.

В Linux и macOS команда интерпретатора может называться `python3`.

## Результаты

- **Среднее время запроса, мс** — сумма длительностей десяти скачиваний, делённая на десять и переведённая в миллисекунды. Замер монотонным таймером включает установку соединения, ожидание сервера и чтение ответа.
- **Общий объём, байт** — сумма фактически прочитанных тел ответов. HTTP-заголовки в объём не входят.
- **Скорость, Мбит/с** — общий объём в байтах × 8 / суммарное время скачиваний в секундах / 1 000 000. Это эффективная скорость получения данных с выбранного сервера.

Тайм-аут ожидания сетевой операции — 30 секунд. При ошибке HTTP, сетевом сбое или обрыве ответа с объявленным размером скрипт сообщает номер запроса и завершается с ненулевым кодом. Статистика выводится только после десяти успешных скачиваний.

## Локальная проверка

Локальный запуск помогает проверить работу скрипта и подсчёт байтов. Для замера скорости через интернет используйте ссылку на Google Диск из примера или свой внешний URL.

В одном терминале из каталога проекта запустите:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Во втором терминале из того же каталога выполните:

```sh
python benchmark.py http://127.0.0.1:8000/README.md
```

Общий объём должен равняться десятикратному размеру README в байтах. Для запуска автоматических тестов выполните `python -m unittest -v`. Тесты сами поднимают временный HTTP-сервер на loopback и работают без интернета.
